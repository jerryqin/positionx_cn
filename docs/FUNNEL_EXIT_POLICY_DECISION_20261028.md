# Funnel 退出合同：待决定的最小差异（2026-10-28）

状态：`FUNNEL_FULL_MODEL_BLOCKED_EXIT_POLICY`。本文是未批准建议，不是退出协议或 APPLY。

已有规则是 `RET120_EXECUTION_FUNNEL_V0_1_2` 的候选、突破回踩确认、原排序、价格区间和风险预览。
`stop_raw = breakout_level_raw × (1 - invalidation)`，其中现有 `invalidation=0.015`，目前只参与
风险预算的每股风险计算。没有代码将它应用于持仓退出。`preferred_horizon` 只是 prior 解释标签，
不构成持有期。现有合同明确退出未资格化，不能输出 Funnel 持仓或收益。

`risk_preview.board_lot=100` 属于执行数量的通用硬编码：配置明确是 preview，要求下一交易日按
实际入场价重新计算；实现没有按证券区分。此次仅在有日期化证券规则的调用中拆分为
`minimum_order_quantity` 与 `quantity_step`。科创板采用最低200股、其后递增1股；预算不足为
`SKIP_MIN_ORDER_RISK`，不向上加仓。风险预算、最大权重和 prior/结构排序不变；Deep/RET120
研究单位不变。旧预览不重写，未知分类仍保留排名并明确影响。

推荐的最小补全方案是**只增加固定保护性退出，不加入止盈、追踪优化或其他模型持有期**：
候选实际入场时冻结当时已有 `stop_raw`；合法持有后，以有效收盘价触及该固定价作为退出计划
的生成条件，计划在下一可交易时点按真实原始价格及可成交证据执行。停牌或不可成交时明确延迟，
不假设止损价能够成交。该方案无需新增止损比例，但会首次产生持仓退出及实际跳空损失。

需要用户决定的只有以下合同内容；批准前均不实施：

| 必须决定的内容 | 推荐选择及改变的行为 |
|---|---|
| 止损位冻结、触发与成交时点 | 入场时冻结既有 `stop_raw`，有效收盘触及后生成下一可交易日开盘退出计划；不把盘后得知的触发追填为同日成交。需批准整仓退出、T+1、停牌及跌停不可成交的延迟规则。 |
| 成本与价格证据 | 明确本模型的佣金/税费/滑点数值及舍入合同，并绑定原始成交价、有效交易规则与成交限制；不复制 Deep/RET120 成本或假设按止损价成交。 |
| 非止损终止条件 | 推荐首版不设止盈及最长持有期；这可能长期持有未触发保护价的项目。必须明确接受这一行为，或另行批准具体终止条件，不能把 prior 的期限标签当作批准值。 |

候选、结构、价格 Gate、全部候选排序及具备资格的风险预览继续输出；完整模型与收益仍阻断。
